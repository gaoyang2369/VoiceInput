# 轻声输入 · VoiceInput

面向 Windows 的语音输入工具：用 SenseVoice 在本地识别语音，再按需通过 DeepSeek 整理文字、翻译成英文，或围绕选中文本进行语音问答。交互灵感来自 Typeless。

## 功能与快捷键

| 功能 | 开始快捷键 | 结果 |
| --- | --- | --- |
| 听写 | 右 Alt | 去口头禅、去重复、补标点，按语义分段和列点 |
| 英文翻译 | 右 Alt + 右 Shift | 将口述整理成自然英文 |
| 选中文本问答 | 右 Alt + 空格 | 先整理口述问题，再结合所选文字回答 |

轻按后松开全部按键即可触发，不用一直按住。再按原组合键或单独右 Alt 结束；录音中按其他已配置快捷键也只结束当前任务。翻译组合键的 Alt 和 Shift 都在键盘右侧，先按哪个均可；问答先按住右 Alt，再按空格。

- 录音时显示胶囊浮条和实时音量波形，左侧 × 取消，右侧 ✓ 完成。
- 浮条中的 `EN` 表示英文翻译，`?` 表示选中文本问答；处理期间播放加载动画。
- 听写和译文默认粘贴回原输入窗口，不按回车、不发送消息；可在设置中关闭自动粘贴。
- 问答以白色圆角卡片显示问题和答案，可复制、选择文字、滚动阅读和拖动顶部位置。
- 卡片优先出现在选区附近；无法取得选区坐标时，使用触发时的鼠标位置。默认宽度约 720 像素，按系统缩放并限制在屏幕工作区内。

## 安装与启动

需要 Windows 10/11、64 位 Python 3.12 或 3.13，并安装 Python 自带的 Tkinter。开发环境使用 Python 3.13；当前固定依赖不支持 Python 3.11。首次安装依赖、下载模型，以及使用 DeepSeek 时需要网络。

1. 下载源码或克隆本仓库，将整个目录保留在可写位置。
2. 双击 `start.bat`。首次启动会创建 `.venv` 并安装 `requirements.txt`；依赖清单改变后也会重新检查安装。
3. 在设置中点击“下载语音模型”。模型来自 sherpa-onnx 官方 SenseVoice 发布包，模型文件约 230 MB。
4. 如需文字整理、翻译或问答，填写自己的 DeepSeek 密钥并保存，选择账户可用的模型名称。默认名称为 `deepseek-flash`，可在设置中修改。
5. 选择麦克风，先用“开始录音”按钮检查识别结果，再点击“保存设置并转到后台”。

不使用 DeepSeek 时，可关闭“DeepSeek 整理”，仅使用本地听写。翻译和问答始终需要 DeepSeek 密钥。

已保存密钥且本地模型就绪时，正常启动会自动进入后台。从系统托盘的麦克风图标打开设置、复制结果或退出；图标可能在托盘折叠区域中。也可双击 `打开设置.bat`，或再次运行启动脚本打开已有实例的设置。关闭设置窗口会转入后台，退出程序请使用托盘菜单。本项目未配置开机自启。

## 选中文本问答

1. 在网页、文档或编辑器中选中文字，保持该窗口在前台。
2. 按右 Alt + 空格并松开，等待浮条出现 `?` 和录音波形，再说出问题，例如“解释这一段”或“总结成三点”。
3. 再按右 Alt 结束。程序先整理口述问题，再将整理后的问题和所选材料交给模型。
4. 在选区附近的卡片查看答案，点击“复制”复制完整答案，× 关闭；点击卡片后也可按 Esc 关闭。

问答不会自动替换原选中文字。卡片显示整理后的问题，设置中的“识别原文”保留原始转写。可以修改原文，再点击“重试上次任务”；重试会沿用原模式、选中文本和位置。

选文优先通过 Windows UI Automation 读取；不支持该接口的应用会尝试发送 Ctrl+C，并检查是否产生新的剪贴板内容。备用复制会覆盖原剪贴板。未取得有效内容时会提示，不启动录音。单次选文最多 20000 字，超过时需缩小范围。

## 数据、密钥与费用

| 模式 | 发往 DeepSeek 的内容 | 每次模型请求数 |
| --- | --- | --- |
| 纯本地听写 | 无 | 0 |
| 整理听写 | 本地转写文字 | 1 |
| 英文翻译 | 本地转写文字 | 1 |
| 选文问答 | 第一轮发送口述问题；第二轮发送整理后的问题和所选文字 | 2 |

录音在本机内存中识别，客户端不上传、不保存录音；转写、答案和问答上下文不写入历史文件。模型服务请求按你的 DeepSeek 账户用量计费，问答的两轮处理会增加等待时间和模型用量。

保存的密钥放在 Windows 凭据管理器中，不写入项目配置。程序优先使用保存的密钥，否则读取启动环境中的 `DEEPSEEK_API_KEY`；也可只在设置密码框中填写供本次使用。程序不会自动读取 `.env` 文件。

`settings.json` 只保存模型名称、麦克风和功能开关。模型、虚拟环境、个人设置与 `.env*` 均已加入 `.gitignore`。自动输入和复制答案都会覆盖系统剪贴板。

## 限制与排查

- 单次录音最长 90 秒，结束后统一处理，不支持边说边出字。
- 自动粘贴要求原窗口仍在前台、修饰键已松开且录音没有丢帧；不满足时保留结果供手动复制。
- 选文与粘贴受目标应用支持和权限等级影响，特殊绘制界面、受保护区域或管理员程序可能无法使用。
- 问答没有联网搜索能力。文字整理、翻译和回答仍需核对，人名、数字、否定和专业词尤其如此。
- 快捷键无响应时，先退出旧实例，检查设置底部的监听状态；托盘菜单也提供三个模式的入口。
- 无声音时检查 Windows 麦克风权限、所选设备和音量波形。无法启动时查看启动窗口的错误信息；开发调试可直接运行 `.venv\Scripts\python.exe app.py --settings`。
- 整理或问答失败后，原始转写仍保留，可修改并重试。若依赖环境损坏，可重新创建 `.venv`，模型和凭据可继续使用。

## 开发与测试

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe -m pip check
```

测试需要 Windows，包含 Tk 窗口、系统快捷键钩子和 UI Automation 组件检查。音频、模型请求、用户选文和剪贴板操作在业务测试中使用模拟数据，不需要真实密钥或下载语音模型。

仓库提供 Windows / Python 3.12、3.13 的 GitHub Actions 工作流；实际云端运行结果以上传后的 Actions 为准。代码结构、测试边界和修改约定见 [开发说明](docs/DEVELOPMENT.md)。
